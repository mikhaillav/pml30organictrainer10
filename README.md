# Тренажер по органическим соединениям для 10 класса ФМЛ30

Мне поставили два за эту контрольную и у меня есть 4 дня чтобы все выучить и не получить два в году :((

## Команды

```bash
npm install
npm run dev
npm run build
```

`npm run build` собирает один файл `dist/index.html`: JS, CSS, JSON-данные и картинки из `pictures/1.png` ... `pictures/30.png` встраиваются внутрь HTML.
